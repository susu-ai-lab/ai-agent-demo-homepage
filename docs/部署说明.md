# Vercel + Render 部署说明

这套部署拆成三个独立服务：

- 作品集主页：部署到 Vercel，只负责项目介绍和跳转。
- 服装商品尺码风险协同处理中心：部署到 Render，作为可点击业务 Demo。
- AIhot 趋势雷达：部署到 Render，作为可点击业务 Demo。

## 一、作品集主页上 Vercel

1. 把 `AI作品集主页-可部署版` 单独上传到一个 GitHub 仓库。
2. 登录 Vercel，选择 `Add New Project`。
3. 选择这个 GitHub 仓库。
4. Framework Preset 选择 `Other`。
5. Build Command 留空。
6. Output Directory 留空。
7. 点击 Deploy。
8. 部署成功后，拿到类似 `https://xxx.vercel.app` 的链接。

后面两个 Demo 在 Render 部署成功后，修改：

```text
public/config.js
```

把占位链接替换成真实 Render 链接：

```js
window.DEMO_LINKS = {
  retailAgent: "https://你的电商-agent-demo.onrender.com",
  aiHot: "https://你的-aihot-demo.onrender.com"
};
```

重新提交 GitHub 后，Vercel 会自动更新。

## 二、Demo 项目上 Render

两个 Demo 都建议单独建 GitHub 仓库，再分别在 Render 创建 Web Service。

### 服装商品尺码风险协同处理中心

Render 配置建议：

```text
Name: retail-size-risk-agent-center
Environment: Node
Build Command: npm install
Start Command: npm start
```

环境变量：

```text
NODE_VERSION=20
DEEPSEEK_API_KEY=你的 DeepSeek Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

如果使用 OpenAI：

```text
OPENAI_API_KEY=你的 OpenAI Key
OPENAI_MODEL=gpt-5.2
OPENAI_BASE_URL=https://api.openai.com/v1
```

### AIhot 趋势雷达

Render 配置建议：

```text
Name: aihot-trend-radar
Environment: Node
Build Command: npm install
Start Command: npm run web
```

环境变量：

```text
NODE_VERSION=20
AI_PROVIDER=dashscope
AI_API_KEY=你的模型服务 Key
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_MODEL=qwen-plus
AI_FILTER_MODEL=qwen-turbo
ANALYSIS_MODE=two_stage
```

说明：`npm run web` 只启动网页看板，适合公开演示。如果要定时抓取和推送，可以另建后台 Worker，不建议和公开 Demo 页面混在一个服务里。

## 三、简历附件怎么放

简历里建议只放 Vercel 主页链接，例如：

```text
AI 应用项目合集：https://xxx.vercel.app
```

主页里再放两个 Demo 的按钮。这样面试官只需要打开一个入口，不需要理解本地启动方式。

## 四、安全注意

- 不要把 `.env`、`.env.local`、API Key 上传到 GitHub。
- Render 环境变量在后台配置，不写进代码。
- 公开 Demo 使用模拟数据，不接真实淘宝、京东、抖音账号。
- Demo 只做只读分析和模拟执行，不做真实退款、库存修改或订单操作。
