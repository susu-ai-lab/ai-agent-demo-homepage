MAIN PROJECT

主项目

Agentic Business Workflow 本地演示

服装商品尺码风险协同处理中心

服装电商里，尺码咨询、偏大偏小评价、退换货、断码和库存积压往往分散在客服、商品、售后、库存多个系统里。这个 Demo 模拟 Agent 如何读取多系统数据、规划任务、分析问题链路，并把建议分发给对应角色审批和模拟执行。

Demo 可操作流程：进入 Demo 后，可创建服装商品尺码风险事件，加载客服、商品、售后、库存样例数据，触发 Planner Agent 拆解任务，查看各业务 Agent 分析结果，处理角色审批待办，并生成最终处理报告。

业务价值：通过识别尺码信息表达、客服话术、退换货原因和尺码库存结构之间的关联，帮助业务团队减少重复咨询、降低退换货和差评风险，并优化热门/冷门尺码库存处理。

业务异常事件 多系统数据读取 Planner 任务规划 子 Agent 分析 角色审批 模拟执行 ROI 反馈

核心 ROI 指标

尺码咨询率下降 尺码相关退货率下降 客服转人工率下降 差评率下降 商品转化率提升 热门尺码缺货率下降 冷门尺码库存周转提升 跨部门排查时间缩短

AGENT CAPABILITY

Agent 能力如何体现在项目里

01 规划能力

Planner Agent 根据业务异常拆解任务，决定先分析客服、商品、售后还是库存数据。

02 工具调用

业务 Agent 分别读取客服会话、商品评价、退换货记录和尺码库存样例数据。

03 协同能力

协同 Agent 将客服、商品、售后、库存结论串成完整问题链路。

04 审批能力

客服话术、详情页修改、售后策略和补货建议进入对应角色审批，不由 Agent 直接执行。

05 反馈闭环

系统记录处理建议、审批结果和 ROI 指标，用于后续复盘。
